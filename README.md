# 📊 Data Analytics Portfolio

Welcome to my Data Analytics portfolio! This repository showcases end-to-end projects focused on **Power BI**, **SQL**, and **Python (Matplotlib)**.

---

## 📁 Repository Structure

### 1. 📈 [Power BI Dashboards](./power-bi)
Interactive dashboards and end-to-end business intelligence reports:
* **Interactive Dashboards**: Business performance tracking, KPI reporting, and data storytelling.
* **Data Modeling & DAX**: Data transformation using Power Query, star schema modeling, and custom DAX measures.

### 2. 🐍 [Python & Data Visualization](./python-matplotlib)
Data visualization and exploratory analysis using Python, Pandas, and Matplotlib:
* **`data_visualization.py`**: Olympic athletes' body variability analysis using error bars (`yerr`).
* **`co2_temp_analysis.py`**: Multivariate analysis between CO₂ emissions and temperature changes over time (Scatter Plot).
* **`weather_style_analysis.py`**: Customization of charts for technical reports, layout resizing, and high-resolution export (300 DPI).

### 3. 🗄️ [SQL Challenges](./sql-challenges)
Database queries and data manipulation techniques:
* **`05_temp_tables.sql`**: Usage of Temporary Tables (`TEMP TABLE`), CTEs, and aggregations for query optimization and analysis.

* **Languages:** SQL, Python
* **Libraries:** Pandas, Matplotlib
