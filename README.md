# 📊 Data Analytics Portfolio

Welcome to my Data Analytics portfolio! This repository showcases practical projects focused on **SQL**, **Python (Matplotlib)**, and **Power BI**.

---

## 📁 Repository Structure

### 1. 🐍 [Python & Data Visualization](./python-matplotlib)
Data visualization and exploratory analysis using Python, Pandas, and Matplotlib:
* **`data_visualization.py`**: Olympic athletes' body variability analysis using error bars (`yerr`).
* **`co2_temp_analysis.py`**: Multivariate analysis between CO₂ emissions and temperature changes over time (Scatter Plot).
* **`weather_style_analysis.py`**: Customization of charts for technical reports, layout resizing, and high-resolution export (300 DPI).

### 2. 🗄️ [SQL Challenges](./sql-challenges)
Database queries and data manipulation techniques:
* **`05_temp_tables.sql`**: Usage of Temporary Tables (`TEMP TABLE`), CTEs, and aggregations for query optimization and analysis.
